# shared

- `params/params.json` — the parameter registry. Contract in
  `spec/DOCS-parameters.md`. Edit here, then `make gen-params`.
- `rooms/rooms.json` — the slice layout (D24). Edit here, then `make gen-rooms`.
- `replay/slice_trace.json` — one scripted run of the slice (inputs + expected
  event ticks), generated by `proto-godot/tests/replay.gd -- --write`. Every
  prototype's sim test replays it; regenerate after a layout or registry change.
