# Input map (fixed, D05)

Both devices are always active. No rebinding. Stick dead zone fixed at
0.25 (not a tunable: changing it is a decision).

| Action | Keyboard | Gamepad |
|---|---|---|
| Move left / right | A / D, ← / → | left stick X, d-pad |
| Jump | Space, W, ↑, Z, K | south button (A / Cross) |
| Pause / resume | Esc, P | Start |
| Dismiss start gate (web) | any key | any button |
| Debug overlay (debug build) | F1 | — |
| Reload params (debug build) | F5 | — |
| Dump snapshot (debug build) | F6 | — |

Quit: close the window or tab (D18).
